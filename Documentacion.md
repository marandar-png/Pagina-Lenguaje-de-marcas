1.-Instrucciones de inicio/ejecución de vuestra web (Obligatorio)

clonar el repositorio con : git clone https://github.com/marandar-png/Pagina-Lenguaje-de-marcas

instalar dependencias: Navegando a la raíz del proyecto y ejecutando: npm install

Configurar variables de entorno: Cree un archivo .env en la raíz con las siguientes claves:
PORT=3000
MONGO_URI= (Su cadena de conexión a MongoDB)
JWT_SECRET= (Una clave secreta para la firma de tokens)

iniciamos el servidor con : npm start

Visualización: Acceda a http://localhost:3000 en su navegador.
